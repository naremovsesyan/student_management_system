
# Student Management System

A student management application built using C, HTML, CSS and JavaScript.

## Features

- Dashboard with student statistics
- Student management
- Add and edit students
- Search students
- Academic analytics
- C backend using Mongoose HTTP server

## Technologies

- C
- HTML5
- CSS3
- JavaScript
- Mongoose

## How to run

Compile the backend using GCC:

```bash
gcc main.c student.c mongoose.c -o student_system.exe -lws2_32 -lbcrypt
```

Run:

```bash
./student_system.exe
```

Open in your browser:

http://localhost:8000
